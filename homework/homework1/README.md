### *Zoo ERP — Homework #1 (SOLID + DI)*

#### 1. Цель проекта

Реализация доменной модели зоопарка с учётом принципов SOLID и внедрением зависимостей через DI-контейнер Spring.

#### 2. Основные элементы системы

* **Животные**: Rabbit, Monkey, Tiger, Wolf
* **Интерфейсы**: Alive, Inventory
* **Иерархия вещей**: Thing, Table, Computer
* **Ветеринарная клиника**: принимает решение о приёме животного
* **Zoo** — главный агрегатор
* **AnimalFactory** — фабрика животных
* **ConsoleRunner** — интерфейс взаимодействия через консоль

#### 3. Учтённые требования

* Приём животных с проверкой здоровья
* Добавление вещей на баланс
* Подсчёт общего количества корма
* Список животных, доступных для контактного зоопарка
* Удаление инвентарного объекта
* Вывод инвентаря и животных

#### 4. SOLID

* **S** — каждый класс делает только своё
* **O** — можно добавлять животных без изменения существующего кода
* **L** — Herbo / Predator корректно наследуют Animal
* **I** — разделили Alive и Inventory
* **D** — Zoo зависит от интерфейсов AnimalFactory и VeterinaryClinic

#### 5. DI-контейнер

Конфигурация помещена в `AppConfig.java`, внедрение зависимостей происходит через Spring.

#### 6. Инструкция по запуску

```bash
./gradlew clean build
java -jar build/libs/homework1.jar
```
